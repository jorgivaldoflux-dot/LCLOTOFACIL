# Lotofácil — Gerador de Jogos

## Instalar no celular

Publique a pasta em um endereço HTTPS (por exemplo, GitHub Pages, Netlify ou Vercel). Depois, abra o endereço no celular:

- **Android/Chrome:** toque no menu do navegador e escolha **Instalar aplicativo** ou **Adicionar à tela inicial**.
- **iPhone/Safari:** toque em Compartilhar e escolha **Adicionar à Tela de Início**.

Após a primeira abertura, o app pode ser aberto pelo ícone e continua disponível sem internet. A consulta ao último resultado, naturalmente, ainda precisa de conexão.

Abra `index.html` no navegador para usar a aplicação.

1. Informe o número do concurso e as 15 dezenas sorteadas, ou clique em **Buscar último resultado**.
2. Escolha as dezenas fixas em cada grupo.
3. Informe quantas dezenas aleatórias de cada grupo entram em cada jogo.
4. Quando a soma for 15, clique em **Gerar 4 jogos**.

O botão de consulta tenta usar o serviço da Caixa. Caso a consulta seja bloqueada pelo navegador ou o serviço esteja indisponível, basta informar o resultado manualmente. Para uma versão publicada, o ideal é conectar esse botão a um pequeno serviço próprio que consulte a fonte oficial, evitando bloqueios de navegador.
